# supabase/

Router only — see the leaf files for anything you need to act on.

- `migrations/` — hand-written, numbered schema SQL. Go here to add or change a table, enum, index, RLS policy, or trigger.
- `seed/` — demo data applied after migrations. Go here to add or change fixture rows for local/demo environments.

Full schema reference (ERD, RLS policy table, view/RPC definitions): `docs/database.md`.
